# Hamid Pharmacy Website

This repository contains a small static website for "شركة حميد للأدوية" (Hamid Pharmacy).

- Files are in Arabic and located at the repository root.
- The site is intended to be published with GitHub Pages from the `gh-pages` branch.

How to publish (via GitHub web UI):

1. Go to repository **Settings → Pages**.
2. Under **Source**, choose branch: `gh-pages` and folder: `/ (root)`.
3. Make sure the repository is public so GitHub Pages can publish it.
4. Wait a minute and visit: https://hamid771676-ui.github.io/hamid/

If pages show a blank screen, try these steps locally:

```bash
# preview locally
python3 -m http.server 8000
# then open http://localhost:8000
```

This README was added to help GitHub show the project information and improve Pages behavior.
